Privacy Policy

My Script Collector

Last updated: July 2026

Overview

This plugin respects your privacy.

The plugin does not collect any personally identifiable information (PII). No information is collected unless you explicitly choose to enable anonymous usage statistics.

If you decline anonymous analytics, no data is collected or transmitted.

What Information May Be Collected

When anonymous analytics are enabled, the plugin may collect only anonymous usage statistics, including:

  • Number of times the plugin is launched
  • Launch timestamps
  • Number of script executions
  • Anonymous usage events (such as button clicks)
  • Adobe application version in which the plugin is running (for example, Photoshop 2026)
  • Operating system name and version (for example, Windows 11 or macOS)
  • A randomly generated anonymous installation identifier

What Is NOT Collected

  • Name
  • Email address
  • Adobe ID
  • IP address
  • Computer or device identifier
  • Hardware serial numbers
  • User account name
  • File names
  • Folder paths
  • Script names
  • Extension names
  • Project contents
  • Documents or images
  • Any information that could identify an individual user

The anonymous installation identifier is randomly generated and is not linked to your computer, operating system installation, Adobe account, or any personal information.

Purpose of Data Collection

Anonymous usage statistics are collected solely to improve the plugin, understand general usage patterns, identify stability issues, and prioritize future development.

Because the collected information cannot reasonably identify an individual, the collected analytics are treated as anonymous statistical data rather than personal data.

User Consent

Anonymous analytics are collected only after your explicit consent.

You may decline analytics at any time. If you decline, the plugin will not collect or transmit any usage data.

Data Sharing

Anonymous analytics are never sold.

They are not shared with third parties except when required to operate the anonymous analytics service or when required by applicable law.

Data Security

Reasonable technical and organizational measures are used to protect the collected anonymous data.

Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. The latest version will always be available on this page.
